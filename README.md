# LKami9幻化助手

从「石之家」幻化截图识别装备与染剂，显示持有情况与获取方式，并可写入游戏内幻化模板。

GitHub：<https://github.com/LKami9/LKami9-huanhua-zhushou>

在线模块清单：

```text
https://raw.githubusercontent.com/LKami9/LKami9-huanhua-zhushou/main/TreeHouseModules.json
```

## 功能

| 功能 | 说明 |
|---|---|
| 截图识别 | 剪贴板图片或图片文件路径；使用系统自带 OCR，**完全离线** |
| 装备与染剂 | 自动判定槽位（不依赖截图里的槽位标签）；模糊匹配会打问号标注 |
| 手动修改 | 识别不准的装备 / 染剂可粘贴正确名称修正；未识别的文本可手动指派 |
| 持有检测 | 装备栏 / 背包 / 兵装库 / 投影台 / 收藏柜 / 雇员 / 部队箱 / 房屋仓库 |
| 获取方式 | 显示每件装备的获取途径（NPC、坐标、所需材料）与是否可交易 |
| 染剂说明 | 区分色名与染剂道具；含通用 / 追加 / 特制染剂的合并处理 |
| 写入模板 | 写入游戏内幻化模板并自动染色，支持指定模板号（1~20） |
| 应用模板 | 投影（穿上）指定模板 |
| 本地试穿 | 不需要投影台或持有装备；支持装备、染剂、发型和眼镜，自动补回模型重置 |
| 独立窗口 | 主界面改为可移动、可缩放的独立窗口，不再挤在 Omni 设置页中 |
| 角色检视快捷栏 | 打开游戏角色查看窗口时，在旁边显示试穿、保存预设、复制分享文本、清除和打开主窗口按钮 |
| 幻化预设 | 整合 Omni「更好的幻化管理」等价功能：保存识别结果、读取角色查看窗口、导入 Omni 已有预设、逐部位编辑、复制分享文本、删除 |
| 套装绑定 | 每条预设可绑定一个套装，切换套装时自动开始对应本地试穿 |

## 使用

```
1. 走到投影台前，手动打开投影台并切到「幻化模板」界面
2. 识别截图（点「从剪贴板识别」或填路径后「识别这个文件」）
3. 目标模板输入编号（按回车确认）→「写入模板」→ 在游戏里点「保存」
4. 点「应用模板」投影
```

> 「写入模板」与「应用模板」需要投影台的「幻化模板」界面处于打开状态。

## 幻化预设

- 识别完成后可在「⑤ 幻化预设」中保存当前结果。
- 打开游戏的角色查看窗口后，可直接读取完整幻化、染剂、发型与眼镜。
- 可导入 OmniToolbox 的 `BetterGlamourManagement.json` 中已有预设。
- 预设支持逐部位修改装备与双染剂、绑定套装、复制 Omni 兼容的分享文本。

## 独立窗口

- 在 Omni 模块设置中点击「打开幻化助手窗口」。
- 或在游戏内执行 `/omni LKami9GlamourHelper open`。
- 打开任意玩家的角色查看窗口后，助手会在窗口旁显示快捷操作栏。
