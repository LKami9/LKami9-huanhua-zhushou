# LKami9幻化助手

从「石之家」幻化截图识别装备与染剂，显示持有情况与获取方式，并可写入游戏内幻化模板。

## 功能

| 功能 | 说明 |
|---|---|
| 截图识别 | 剪贴板图片或图片文件路径；使用系统自带 OCR，**完全离线** |
| 装备与染剂 | 自动判定槽位（不依赖截图里的槽位标签）；模糊匹配会打问号标注 |
| 手动斧正 | 识别不准的装备 / 染剂可粘贴正确名称修正；未识别的文本可手动指派 |
| 持有检测 | 装备栏 / 背包 / 兵装库 / 投影台 / 收藏柜 / 雇员 / 部队箱 / 房屋仓库 |
| 获取方式 | 显示每件装备的获取途径（NPC、坐标、所需材料）与是否可交易 |
| 染剂说明 | 区分色名与染剂道具；含通用 / 追加 / 特制染剂的合并处理 |
| 写入模板 | 写入游戏内幻化模板并自动染色，支持指定模板号（1~20） |
| 应用模板 | 投影（穿上）指定模板 |

## 使用

```
1. 走到投影台前，手动打开投影台并切到「幻化模板」界面
2. 识别截图（点「从剪贴板识别」或填路径后「识别这个文件」）
3. 目标模板输入编号（按回车确认）→「写入模板」→ 在游戏里点「保存」
4. 点「应用模板」投影
```

> 「写入模板」与「应用模板」需要投影台的「幻化模板」界面处于打开状态。
